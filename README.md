# Java学習用リポジトリ ☕️

このリポジトリは、コラボレーター同士で一緒にJavaの基礎から実践までを学び、進捗を管理しながら学習を進めるためのリポジトリです。

## 🎯 目的
- ペアプログラミングやコードレビューを通じた、実践的なJavaスキル・オブジェクト指向の習得
- Issueを活用したタスク管理と進捗の可視化
- アウトプット（コードの共有）による理解の定着

---

## 📂 ディレクトリ構成
学習の進捗に合わせて、以下のような構成でコードや演習課題を追加していきます（例）。

```text
java-learning/
├── src/
│   ├── chapter01/Hensu     # 基本構文・変数・制御構文など
│   ├── chapter02/Object language        # オブジェクト指向（クラス、継承、ポリモーフィズム）など
│   └── chapter03/ # Error handle        # 例外処理など
├── docs/                     # 学習メモや資料など
└── README.md
